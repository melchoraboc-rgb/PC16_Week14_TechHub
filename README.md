PC16 Week 14 – TechHub Mobile Shopping App

Project Description

TechHub is a mobile shopping app UI prototype created using Flutter and Dart for the PC16 – Mobile Development with Lab Week 14 activity.

The project demonstrates two related screens with a consistent dark theme, blue accents, and organized mobile layouts.

Screens Included

1. Product Listing Screen
- Displays available gadgets and smartphones.
- Includes a search bar.
- Shows product names, ratings, and prices.
- Includes a bottom navigation bar.

2. Product Details Screen
- Displays product information.
- Shows product price and rating.
- Includes color and storage options.
- Displays technical specifications.
- Includes an Add to Cart button.

Technologies Used

- Flutter
- Dart
- DartPad

Project Purpose

The purpose of this activity is to practice building static mobile user interfaces using Flutter widgets such as Scaffold, Row, Column, Stack, Container, and StatelessWidget.
